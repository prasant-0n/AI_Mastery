# Phase 00 — Engineering Foundation

## Purpose

Build the engineering foundation required to understand, implement, debug, design, and interview for modern backend, AI, and distributed software systems.

This phase is not about memorizing definitions. It establishes the mental models used throughout the rest of AI Mastery.

## Outcomes

By the end of this phase, you should be able to:

- reason about programs, processes, memory, and execution
- understand data types, references, mutation, and state
- reason about synchronous and asynchronous execution
- understand concurrency and parallelism
- analyze time and space complexity
- understand errors and failure boundaries
- use Git professionally
- read technical documentation and unfamiliar codebases
- debug systematically instead of guessing
- explain engineering decisions in interviews
