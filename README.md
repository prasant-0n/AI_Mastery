# AI Mastery

A production-oriented curriculum for becoming an AI-native software engineer.

## Career Target

**Backend / Systems Engineer → AI Engineer → Production AI Systems Engineer**

This repository combines software engineering, AI engineering, production operations, interview preparation, and progressively harder projects.

## Learning Loop

**Learn → Understand → Implement → Break → Debug → Design → Explain → Interview → Project → Document → Revise**

## Mastery Levels

| Level | Meaning |
|---|---|
| L0 | Not started |
| L1 | Familiar |
| L2 | Can explain |
| L3 | Can implement |
| L4 | Can debug |
| L5 | Can design |
| L6 | Can defend trade-offs |
| L7 | Can apply in production |

## Repository Areas

- `00-*` through `53-*` — curriculum phases
- `projects/` — progressive production projects
- `patterns/` — engineering and interview patterns
- `scenarios/` — scenario-based questions
- `debugging-labs/` — broken-system investigations
- `failure-modes/` — production failure catalog
- `experiments/` — controlled engineering/AI experiments
- `interview/` — interview preparation
- `docs/` — architecture, ADRs, security and operations
- `career/` — role and market mapping

## Completion Rule

A phase is complete only when its theory, implementation, scenarios, debugging, interview work, architecture exercise, project work, tests, documentation, and review gate are complete.

## Core Principle

> Every important concept must answer: **Can I explain it, implement it, design with it, debug it, and defend the decision in an interview?**
